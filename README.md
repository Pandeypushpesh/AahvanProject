# 🌐 Ahvaan Telecom Registration System (Backend)

The **Ahvaan Telecom Registration System** backend is a secure, scalable, and cloud-integrated system built using **Node.js**, **Express.js**, and **MongoDB Atlas**.  
It manages user registrations, OTP verifications, Razorpay-based payments, and admin-controlled form configurations.

---

## 🚀 Tech Stack

| Layer | Technology |
|--------|-------------|
| Backend Framework | Node.js + Express.js |
| Database | MongoDB Atlas (Cloud-based NoSQL) |
| Authentication | JWT (JSON Web Token) |
| Payment Gateway | Razorpay |
| SMS Service | Fast2SMS API |
| Email Service | Nodemailer / Mailgun |
| Security | bcrypt, Helmet, CORS, SSL |
| Deployment | Hostinger / PM2 |

---

## 🧩 Features

- User registration with validation and encryption  
- OTP-based mobile/email verification  
- Razorpay payment integration  
- Admin login and access control (JWT-based)  
- Dynamic form builder for admins  
- MongoDB Atlas cloud storage with secure SSL  
- Weekly database backup and audit logs  
- Error handling and structured API responses
